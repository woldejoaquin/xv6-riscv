## Paso a paso para instalar xv6
1. Necesitamos instalar un emulador para ejecutar Linux en nuestro dispositivo. Nosotros usamos Ubuntu.
2. Clonamos el repositorio que se recomendó en clases y creamos una nueva rama con los nombres de los participantes del grupo.
3. Instalamos las dependencias necesarias 
4. Compilamos el sistema xv6 para luego ejecutarlo
